⚙️ အခြား ဆက်တင်များ (အမြန်နှုန်း / အသံနေအသံထား — သီဟ/နီလာ နဲ့ browser default အသံအတွက်)
မိုက်ခရိုဖုန်းခွင့်ပြုချက် လိုအပ်ပါမည်။ စကားလုံးရိုက်ထည့်ပြီး အသံအမျိုးအစားရွေးကာ "အသံသွင်းမည်" ကိုနှိပ်ပါ၊ ထပ်နှိပ်ပါက ရပ်ပါမည်။ တူညီသည့်စကားလုံးကို အသံအမျိုးအစားအမျိုးမျိုးနဲ့ ထပ်သွင်းနိုင်ပါသည် (ဥပမာ - "မင်္ဂလာပါ" ကို ယောက်ျားသံ၊ မိန်းမသံ နှစ်မျိုးလုံး သိမ်းထားနိုင်သည်)။ စာဖတ်ရန်စာမျက်နှာတွင် ပရိုဖိုင်ရွေးပြီး ဖတ်ခိုင်းနိုင်ပါသည်။
Gemini API key ကို "စာဖတ်ရန်" tab ထဲက "Gemini AI အသံ" အပိုင်းမှာ အရင်ထည့်ထားပါ (ဒီနေရာက ချိတ်ဆက်သုံးပါမည်)။ Movie ဖိုင်ကို Gemini ဆီ တင်ပြီး ဇာတ်ကြောင်းကို ကြည့်ကာ မြန်မာလို အနှစ်ချုပ် (recap) စာသား ရေးပေးမှာဖြစ်ပါတယ်၊ ပြီးရင် အလိုအလျောက် အသံထုတ်ပေးပါမည်။

သတိပြုရန် — ရုပ်ရှင်ဖိုင် အရွယ်အစားကြီးလေ၊ အချိန်ကြာလေ၊ Gemini API ကုန်ကျစရိတ် ပိုများလေ ဖြစ်ပါတယ် (video minute အလိုက် token ကုန်ကျသည်)။ မိနစ် ၁၀–၂၀ အတွင်း clip အတို/trailer/scene တွေနဲ့ စမ်းကြည့်ဖို့ အကြံပြုပါတယ်။ ဖိုင် 2GB အောက်ရှိရပါမည်၊ Gemini ပေါ်မှာ ၄၈ နာရီအတွင်း အလိုအလျောက် ပျက်သွားပါလိမ့်မယ်။
